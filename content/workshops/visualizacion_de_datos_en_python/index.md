## Sobre el Workshop

En este taller dictado por el Ing. Agrónomo Juan Félix Orlowski y tratará sobre cómo visualizar datos utilizando populares librerías de Python como Matplotlib y Seaborn entre otras. A lo largo de la sesión, se explorarán diversas técnicas para representar la información de manera clara, analizando las buenas prácticas de diseño gráfico y estadístico, así como los errores comunes y trampas visuales que se deben evitar al comunicar resultados.
